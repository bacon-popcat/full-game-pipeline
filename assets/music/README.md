# Music

Background tracks for `src/shared/Music.luau`, generated with ElevenLabs Music (`eleven_music_v2_5`,
instrumental, 150 s each) and uploaded as audio assets with the Open Cloud Assets API, the same way
as the sound palette (see `assets/sounds/README.md`). MusicController plays them in a shuffled
order with fades and quiet gaps between them.
